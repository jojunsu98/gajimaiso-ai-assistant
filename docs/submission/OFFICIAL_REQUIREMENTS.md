# 공식 요구사항 대조 — 2026-11-04

출처: 사용자가 이 대화에 제공한 「AI Agent 개발: 나만의 AI 비서 구축」 과제 원문 1~8절. 과제 안내를 새로 받았으므로 이전의 '공식 원문 미확인' 판단을 대체합니다. 제출 폼 주소·평가자 접근 방식은 이 원문에 명시돼 있지 않습니다. 17~20단계는 작업 진행 구분이며 과제 원문의 공식 단계 번호가 아닙니다.

**최종 판정: 핵심 기능은 기존 실행 근거와 코드로 확인됐으며, 부족했던 제출 캡처2종도2026-11-04 실제 촬영으로 보완했습니다. 필수3종·문서 준비 완료입니다. 실제 제출 접수는 별도입니다.**

## 실제 GPT·DB 검증과 이번 추가 호출의 차이

- 2026-10-29 Render 검증: 실제 `POST /api/chat` 1회, HTTP200, `gpt-5.4-mini`, `saved=true`, 목록 표시와 상세 복원 일치. 원본128건과 기존 질문3건은 보존했고 새 검증 질문1건을 저장했습니다. [실행 기록](evidence/render-gpt-2026-10-29.json).
- 기존 격리 Firestore 검증: 생성201, 조회·수정200, 삭제204, 변경 후 통계 및 삭제 후 부재 확인. 실제 DB 쓰기를 수행한 기록이며 모의 DB 검사로 대체한 것이 아닙니다. [CRUD 기록](evidence/crud-isolated-2026-10-29.json).
- 기존 UI 수정/삭제는 [사용자 확인과 HTTP 기록](evidence/crud-user-confirmation-2026-10-29.json)으로 구분합니다.
- '이번 GPT 호출·DB 쓰기0회'는 위 성공을 다시 실행하지 않았다는 뜻입니다. 기능 미구현·전체 개발기간 호출0회라는 뜻이 아닙니다. 최초 요청의 '이미 검증된 항목은 재실행하지 말 것'을 적용했습니다.
